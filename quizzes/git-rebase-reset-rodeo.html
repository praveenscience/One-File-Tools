📖 Git Reset, Rebase & Recovery Cheat Sheet

The Three Reset Modes

Mode Branch Index Working tree
--soft Moved Kept Kept
--mixed (default) Moved Reset Kept
--hard Moved Reset Tracked files reset; untracked kept

Interactive Rebase Verbs

Verb Action
pick Use commit
reword Use commit, edit commit message
edit Use commit, then stop for amending
squash Meld into previous commit; edit combined message
fixup Meld into previous commit; discard this message
drop Leave commit out of the rewritten branch

Recovery & Restoration

Task Command
Find lost commit git reflog
Undo last reset git reset --hard ORIG_HEAD
Rescue to a branch git branch rescue <sha>
Unstage file git restore --staged <file>
Undo a pushed commit git revert <sha>
Transplant range git rebase --onto <new> <upstream> <branch>
Safer force-push git push --force-with-lease
