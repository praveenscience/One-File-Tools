📖 Git Interactive Rebase Manual

What is Interactive Rebase?

Interactive rebase (git rebase -i <base>) allows developers to rewrite commit history before sharing it publicly. You can alter order, combine commits into atomic units, discard accidental secrets, amend messages, and resolve conflicts.

The Rebase Commands:

Command Keyword Action Description
pick p Applies the commit without any changes.
reword r Applies the commit but prompts to rewrite the commit message.
edit e Pauses the rebase at this commit. Allows amending or splitting into multiple atomic commits.
squash s Melds this commit into the preceding commit, combining both commit messages.
fixup f Melds this commit into the preceding commit, discarding this commit's message.
drop d Deletes the commit entirely from history.
⚠️ The Golden Rule of Git Rebasing:

Never rebase commits that have already been pushed to a shared, public branch (like main or production). Rebasing generates new commit SHAs, which causes divergence and headaches for your teammates. Only rebase your local private feature branches!
