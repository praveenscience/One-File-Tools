The Apprentice's Field Guide

Four truths every glassblower — and every JavaScript developer — must know before touching the furnace.

1. Objects are Soft Glass

When you hand someone an object, you hand them the same piece, not a copy. Reshape it, and everyone holding that piece sees the new shape — because there was only ever one piece of glass.

let glass = { color: "amber" };
let apprenticeHolds = glass;
apprenticeHolds.color = "rose";
// glass.color is now "rose" too —
// same reference, same glass.

2. const Locks the Grip, Not the Glass

const only prevents you from swapping which piece your hand holds. You can still reshape the glass in your grip — you just can't grab a different piece entirely.

const glass = { temp: 500 };
glass.temp = 900;      // fine — same piece, reshaped
glass = { temp: 20 };  // TypeError:
// Assignment to constant variable.

3. Mutate the Rack, or Cast a New One

push(), splice(), and index assignment change the array in place — everyone with a reference sees it. Spreading with [...rack] pours the same pieces into a brand new rack, leaving the original untouched.

const rack = [cup, vase];
rack.push(bowl);          // mutates rack directly

const displayRack = [...rack, bowl];
// a NEW array — rack itself is untouched

4. Object.freeze() Cools It Forever

Freezing is the kiln-cooling step. Once cooled, the glass is solid — any attempt to reshape it silently fails (or throws in strict mode). The piece doesn't bend anymore. It cracks instead.

const heirloom = Object.freeze({ color: "gold" });
heirloom.color = "grey";
// strict mode → TypeError: Cannot assign to
// read only property 'color' of object
console.log(heirloom.color); // still "gold"
