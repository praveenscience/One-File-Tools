            Regex Quick Reference & Cheat Sheet
          

          
        


        
        

          
          

            
Anchors & Boundaries

            

              
^ — Start of string/line

              
$ — End of string/line

              
\b — Word boundary

              
\B — Non-word boundary

            

          


          
          

            
Quantifiers

            

              
* — 0 or more (greedy)

              
*? — 0 or more (lazy)

              
+ — 1 or more (greedy)

              
+? — 1 or more (lazy)

              
? — 0 or 1 optional

              
{n,m} — Between n and m times

            

          


          
          

            
Character Classes

            

              
\d / \D — Digit / Non-digit

              
\w / \W — Word / Non-word char

              
\s / \S — Whitespace / Non-whitespace

              
. — Any character (except newline)

              
[a-z] — Character in range

              
[^a-z] — Negated range

            

          


          
          

            
Groups & Lookarounds

            

              
(...) — Capturing group

              
(?:...) — Non-capturing group

              
(?<name>...) — Named capture group

              
(?=...) — Positive Lookahead

              
(?!...) — Negative Lookahead

              
(?<=...) — Positive Lookbehind
